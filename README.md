# SE_Project_TU

Hostel Complaint Management System with a separated frontend and backend structure.

## Project Layout

```text
SE_Project_TU/
  frontend/   Next.js + Tailwind CSS + shadcn/ui
  backend/    Express + TypeScript API scaffold
```

## Frontend

The student dashboard UI lives in `frontend/`.

Useful commands:

```bash
npm run dev:frontend
npm run build:frontend
```

## Backend

The API scaffold lives in `backend/`.

Useful commands after installing backend dependencies:

```bash
npm run dev:backend
npm run start:backend
```
